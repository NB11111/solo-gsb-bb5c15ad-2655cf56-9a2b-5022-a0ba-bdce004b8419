# 木工短料下料优化

供木工工作室使用的短料下料网页。输入**原料长度**、**锯缝宽度**以及各规格的**长度和数量**，
系统先把同规格裁片展开成单片（总裁片数上限 12 片），再通过精确搜索求出**使用原料根数最少**的可行分配，
并显示每根原料的裁片顺序（同根内按长度从大到小，即建议裁切顺序）与余长，结果可在浏览器中直接打印。

## 计算规则

- 同规格按数量展开成独立裁片参与计算（编号 A1、A2…，B1、B2…）；相同长度的多行视为同一规格。
- 优化目标：**原料根数最少**（深度优先精确搜索 + 剪枝，保证全局最优）。
- **只有同一根原料上相邻的两片之间才计一条锯缝**：
  一根原料放 k 片时，占用长度 = 各片长度之和 + (k − 1) × 锯缝宽度；单片独占一根时不计锯缝。
- 每根原料显示：裁片顺序、片数、锯缝条数、已用长度、余长；另给出锯缝总数、总余长与综合利用率。
- 输入校验（错误时返回明确原因）：
  - 原料长度必须大于 0，锯缝宽度必须不小于 0，长度均为正数、数量为正整数；
  - 至少填写一条规格且总片数 ≥ 1；
  - 总裁片数不得超过 12 片；
  - 单片长度超过原料长度时，提示“单片无法放入原料”并指出是哪一条规格。

长度单位保持一致即可（如全部用毫米）。

## 技术栈

Node.js + Express（后端计算 API 与静态页面托管）+ 原生 JavaScript / HTML / CSS（前端，无构建步骤）。

## 单条启动命令（Docker Compose）

```bash
docker compose up --build
```

依赖会在**容器启动时自动安装**（首次启动执行 `npm install --omit=dev`，
`node_modules` 由 Docker 命名卷持久化，后续启动自动跳过安装）。

启动后在浏览器访问：

```
http://localhost:3000
```

## 必要配置

| 配置项 | 方式 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 网页访问端口 | Compose 端口映射 `${PORT:-3000}:3000` | `3000` | 宿主机端口可用环境变量 `PORT` 修改 |
| 容器监听端口 | 容器内环境变量 `PORT` | `3000` | 通常无需修改 |

如需改用 8080 端口访问：

```bash
PORT=8080 docker compose up --build
```

然后访问 http://localhost:8080 。

后台运行与停止：

```bash
docker compose up --build -d   # 后台启动
docker compose down            # 停止并删除容器
docker compose logs -f         # 查看日志
```

## 不用 Docker 的本地运行方式

需要 Node.js 18 及以上。

```bash
npm install
npm start
```

然后访问 http://localhost:3000 。

## 打印方案

计算出方案后点击结果区右上角的 **“打印方案”** 按钮（或浏览器 Ctrl/⌘ + P），
打印样式会自动隐藏输入区与按钮，只输出方案标题、汇总信息和每根原料的裁片示意与顺序。

## 目录结构

```
.
├── Dockerfile              # 容器镜像定义（依赖在容器启动时安装）
├── docker-compose.yml      # Compose 编排（端口、卷、健康检查）
├── docker-entrypoint.sh    # 入口脚本：启动时安装依赖
├── package.json            # 依赖清单（Express）
├── server.js               # Express 服务：静态页面 + /api/optimize
├── cuttingPlan.js          # 输入校验与下料优化核心算法
└── public/                 # 前端原生页面
    ├── index.html
    ├── style.css
    └── app.js
```

## API 说明

`POST /api/optimize`

请求体：

```json
{
  "stockLength": 2440,
  "kerf": 3,
  "items": [
    { "length": 800, "qty": 2 },
    { "length": 600, "qty": 2 },
    { "length": 400, "qty": 1 }
  ]
}
```

输入非法或单片无法放入原料时返回 HTTP 400 与 `{ "ok": false, "error": "明确原因" }`。
